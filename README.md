# HAWK Portfolio

Personal portfolio site for [Hawk327ml](https://github.com/Hawk327ml).

**Stack:** Vite + TypeScript (+ Three.js for `/play`)  
**Live (after Pages):** https://Hawk327ml.github.io

## Local

```bash
npm install
npm run dev
```

Open:

- Portfolio: http://localhost:5173/
- Orb Courier: http://localhost:5173/play/

Do **not** open `play/index.html` via `file://` — ES modules / Three will not load.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push to `main` on `Hawk327ml/Hawk327ml.github.io`. GitHub Actions builds and publishes to GitHub Pages.
